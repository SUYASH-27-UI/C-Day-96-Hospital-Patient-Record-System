# C Day 96 - Hospital Patient Record Management System

## Description
A menu-driven Hospital Patient Record Management System developed using C. It stores and manages basic patient records using a text file.

## Features
- Add patient records
- Display all patients
- Search patients by ID
- Update patient details
- Delete patient records
- Save records permanently

## Files
- `hospital.c` - Main C program
- `patients.txt` - Patient records

## How to Compile
`gcc hospital.c -o hospital`

## How to Run
Windows: `hospital.exe`

Linux: `./hospital`

Keep `patients.txt` in the program's working directory.

## Concepts Used
- Structures
- Arrays
- Functions
- File Handling
- Searching
- CRUD Operations
